# Swap marks and served-as: review sheet (viability test 5)

How to read: **essential** = recipe doesn't work without it. **swappable** = replace with the swap (or anything in the group). **optional** = leave it out. 
**served** is raw / cooked / unspecified, used only for allergy rules (e.g. 'no raw apple'). **amount** is exact / flexible (fine down to the floor) / stretchable (top up with something).

Mark anything you disagree with: put your call in the last column, or just reply in the thread with the recipe and line number.
